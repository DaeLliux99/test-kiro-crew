# Todo List

Aplicación sencilla de lista de tareas hecha con HTML, CSS y JavaScript puro (sin dependencias).

## Características

- Agregar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Filtrar por: todas / pendientes / completadas
- Limpiar todas las completadas
- Contador de tareas pendientes
- Persistencia en `localStorage` (las tareas se guardan en el navegador)

## Uso

Abre `index.html` en tu navegador. No requiere instalación ni servidor.

## Estructura

```
todolist/
├── index.html   # Estructura de la página
├── styles.css   # Estilos
├── script.js    # Lógica de la aplicación
└── README.md
```
